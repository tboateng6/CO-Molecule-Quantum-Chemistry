# CO-Molecule-Quantum-Chemistry
Computational datasets and Python scripts for the theoretical study of CO potential energy curves.
# CO Molecule — Quantum Chemistry Calculations

## Overview

This repository contains the computational datasets, MOLPRO input files, Python scripts, and numerical results associated with a Master's thesis investigating the electronic structure and adiabatic potential energy curves of the carbon monoxide (CO) molecule.

## Research Contents

- MOLPRO input files for ground-state and excited-state calculations.
- Electronic energy datasets obtained using selected quantum-chemical methods.
- Python scripts for plotting potential energy curves.
- Cubic-spline interpolation and minimum-energy calculations.
- Ground-state equilibrium properties and excited-state potential energy curves.
- Supporting spectroscopic analysis results.

## Software

The calculations and analysis were performed using MOLPRO, Python, NumPy, Pandas, Matplotlib, SciPy, and sPystroscopy.

## Reproducibility

The datasets and scripts are provided to support verification and reproduction of the computational results presented in the thesis. Energy values are reported in hartree, and internuclear distances are expressed in bohr.
